# Linux Lab 03 - Password Aging Policy

## Objective

Learn how to:
- View password aging information
- Set minimum password age
- Set maximum password age
- Configure password expiration warnings

---

## Commands

```bash
# Create a new user
sudo useradd labuser

# Set a password
sudo passwd labuser

# View password aging information
sudo chage -l labuser

# Set the maximum password age to 90 days
sudo chage -M 90 labuser

# Set the minimum password age to 7 days
sudo chage -m 7 labuser

# Warn the user 14 days before password expiration
sudo chage -W 14 labuser

# Display the updated settings
sudo chage -l labuser

# InActive
sudo chage -I 10 labuser

#Expired user
sudo chage -E 2027-12-31 labuser
```

---

## Command Explanation

| Command | Description |
|----------|-------------|
| `chage -l` | Display current password aging settings |
| `chage -M 90` | Password expires after 90 days |
| `chage -m 7` | User must wait at least 7 days before changing the password again |
| `chage -W 14` | Warn the user 14 days before the password expires |

---

## Expected Output

```text
Last password change                                    : Jul 31, 2026
Password expires                                        : Oct 29, 2026
Password inactive                                       : never
Account expires                                         : never
Minimum number of days between password change          : 7
Maximum number of days between password change          : 90
Number of days of warning before password expires       : 14
```

---

## What I Learned

- `-m` sets the minimum number of days before a password can be changed again.
- `-M` sets the maximum password lifetime.
- `-W` configures when the user starts receiving password expiration warnings.
- `chage -l` is useful for auditing password policies.\

## Why is this important?

Password aging policies help reduce the risk of compromised passwords by requiring users to change them regularly and preventing frequent password changes that could bypass security policies.
